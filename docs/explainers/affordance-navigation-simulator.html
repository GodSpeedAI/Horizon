NE-01 · PRIORITY TEETH
Unauthorized High-Value Candidate
Even if ranked highest by an advisory ML model, an unauthorized candidate is strictly eliminated from spendable options.
NE-05 · PREREQUISITE TEETH
Approval Is Pending, Not Discarded
requires_approval blocks immediate commit but synthesizes authority:approval as the next spendable prerequisite.
NE-04 · UNKNOWN TEETH
Unknown Authority Remains Unknown
Unknown authority never silently falls back to 'allow' or 'denied'. It produces an unknown severity blocker.
NE-09 · TAMPER TEETH
UI Enablement Grants Nothing
A compromised frontend or agent enabling a blocked button in the DOM has zero effect: the controller enforces gates at intent commit.
NE-11 · FRESHNESS TEETH
Stale Frame Revision Refusal
Submitting an intent against frame revision 1 after frame revision 2 was issued is strictly refused and audited as an attempt.
PE-10 · SETTLEMENT TEETH
Reachable vs Settle Now
Settlement reachability is distinct from should_settle_now; settlement requires an explicit authorized judgment.
