PE-10 · CITATION TEETH
Retrieval Grants No Authority
Context Kernel citations are stamped untrusted_reference by Horizon itself; they cannot authorize actions or rewrite events.
NE-07 · COUNTERFACTUAL TEETH
Invalid Proposal Refusal
A counterfactual with an invalid or contradictory state proposal is refused without executing or mutating.
PE-02 · HONESTY TEETH
Missing Source Explicitly Named
An unknown value must name the missing source that records nothing. Silence is reported, never synthesized.
