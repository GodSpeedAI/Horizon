# src/ui

Renderer-neutral surface projection for the structural skeleton. `surface.ts` accepts a
typed navigation frame and emits a closed surface model whose blocks carry explicit
semantic, Cognate, file or agent source references. It emits no JSX, HTML or executable
markup.

The full cockpit vocabulary and reducer are deferred to T05. Product Actualizer is a donor
for structural patterns only; see `docs/donors.md`.
